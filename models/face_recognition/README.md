# Face Recognition Model

## Expected file

```
models/face_recognition/mobilefacenet.onnx
```

## Model

**MobileFaceNet (w600k_mbf)** — InsightFace MBF face embedding model.

- Architecture: MobileNet-inspired, ~6.9 M parameters
- Input:  `[N, 3, 112, 112]`  float32, (pixel – 127.5) / 128 normalisation, RGB
- Output: `[1, 512]`           L2-normalised embedding vector
- Latency on Pi 5: **~10–20 ms** per face crop
- Recognition: cosine similarity against pre-built embedding database

## Download / Export

### Option A – InsightFace ONNX export

```bash
pip install insightface onnx onnxruntime
python - <<'EOF'
import insightface
model = insightface.app.FaceAnalysis(allowed_modules=["recognition"])
model.prepare(ctx_id=-1)   # CPU
# Export the recognition model
import onnx
# Follow InsightFace export docs for specific model version
EOF
```

### Option B – PyTorch → ONNX export

If you have a MobileFaceNet PyTorch checkpoint:

```bash
pip install torch onnx
python - <<'EOF'
import torch
from your_mobilefacenet_module import MobileFaceNet

model = MobileFaceNet(512)
model.load_state_dict(torch.load("mobilefacenet.pth", map_location="cpu"))
model.eval()

dummy = torch.randn(1, 3, 112, 112)
torch.onnx.export(
    model, dummy, "mobilefacenet.onnx",
    input_names=["input"], output_names=["output"],
    opset_version=12, dynamic_axes=None,
)
EOF
```

### Option C – Pre-converted ONNX from community sources

Search for "MobileFaceNet ONNX" on Hugging Face, GitHub, or model zoos.
Verify the input/output shapes match what is documented above before using.

## Face embedding database

Generated by `scripts/enroll_faces.py`. Stored at:

```
data/face_embeddings/embeddings.pkl
```

Format: `dict[str, np.ndarray]` — person name → mean L2-normalised embedding.

## Is this model optional?

No. Without it, all faces will be classified as UNKNOWN and the
system will not be able to identify known persons.
